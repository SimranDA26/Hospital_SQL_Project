# Hospital SQL Data Analysis Project

## Project Overview

This project is a SQL-based data analysis project built using a fictional hospital dataset.

The objective is to analyze patient information, hospital admissions, doctors, and billing data using MySQL.

## Database Tables

The project contains 4 tables:

- Patients
- Doctors
- Admissions
- Billing

## SQL Concepts Covered

- SELECT, WHERE, ORDER BY
- GROUP BY and HAVING
- Aggregate Functions
- INNER JOIN
- LEFT JOIN
- SELF JOIN
- CROSS JOIN
- UNION and UNION ALL
- Subqueries
- Correlated Subqueries
- CTEs
- CASE Statements
- EXISTS and NOT EXISTS
- Window Functions
- ROW_NUMBER
- RANK
- DENSE_RANK
- LAG and LEAD
- Date and Time Analysis
- Conditional Aggregation
- NULL Handling with COALESCE and NULLIF
- Views
- ROLLUP
- Median Analysis

## Business Analysis

The project answers business questions related to:

- Patient demographics
- Hospital admissions
- Doctor performance
- Department performance
- Revenue and billing analysis
- Emergency vs planned admissions
- Patient admission patterns
- Monthly and yearly revenue trends
- Doctor ranking within departments
- Billing data quality checks

## Tools Used

- MySQL
- MySQL Workbench
- GitHub

## Dataset

The dataset is fictional and was created specifically for this portfolio project for SQL practice and business analysis.
